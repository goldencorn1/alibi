# Alibi Roadmap

This roadmap distinguishes product direction from capabilities already verified in the repository. It does not authorize implementation work or change the v0.7 platform scope.

## Discover

Wallet discovery, deterministic ranking, recent-result metrics, lead-rate and coverage views are in active development. Any future result must retain `recorded`, `live`, `unavailable`, and `insufficient_evidence` states and must not convert ranking performance into an insider, identity, causal, or investment claim.

## Explain

The local/recorded path already demonstrates a trade → evidence → repricing timeline, evidence admission rules, language-window states, cluster dimensions, Agent Console observation, and audit exports. Live source completeness, timestamp calibration, and a reproducible real cluster/language benchmark remain validation work.

## Fit

Delay, order size, order-book slippage, retained-return, and policy comparison are target capabilities. They must remain clearly labeled as target or in development until real evidence and the approved verification gates support them.

## Platform extensions

The repository preserves the broader platform direction: HTTP APIs, MCP, Chrome Extension, WebSocket market triggers, RAG, Solidity, x402, and ERC-8004. Public endpoints, live settlement, chain registration, and store publication are separate acceptance boundaries.

## Non-goals

No roadmap item authorizes custody, signing, trading, copy trading, bridge operations, public release, synthetic Demo data, or unsupported claims about users, performance, coverage, latency, revenue, settlement, or registration.
